# Contribuire a Sinfonia

Grazie per voler contribuire. Sinfonia vuole dimostrare che si può orchestrare
l'AI in modo etico, trasparente e sostenibile.

## I 5 Principi Non Negoziabili

Ogni contributo DEVE rispettare questi principi. Pull request che li violano
verranno chiuse senza discussione.

1. **BYOK** — L'utente fornisce le proprie chiavi.
2. **Rispetto dei limiti dichiarati** — Mai superare un rate limit.
3. **Nessun pooling multi-account** — Una chiave per provider per utente.
4. **Nessuna funzionalità di stealth o anti-ban**.
5. **Trasparenza radicale** — L'utente vede sempre i costi.

## Come Contribuire

1. Forka il repository.
2. Crea un branch: git checkout -b feature/nome-feature
3. Scrivi il codice seguendo PEP 8.
4. Aggiungi test per ogni nuova funzionalità.
5. Assicurati che i test passino: pytest
6. Committa con messaggi chiari (Conventional Commits).
7. Apri una Pull Request.

## Convenzioni di Commit

- feat: nuova funzionalità
- fix: correzione di bug
- docs: documentazione
- chore: manutenzione
- refactor: ristrutturazione
- test: test
